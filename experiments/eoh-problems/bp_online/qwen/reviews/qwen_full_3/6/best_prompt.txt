# PROMPT-BLOCK-START
You are an expert in combinatorial optimization, heuristic design, and bin packing algorithms.
Your mission is to design a novel and high-performing scoring function for the Online Bin Packing problem.

PROBLEM CONTEXT:
- **Task**: Design a score function that assigns scores to bins for placing an item.
  At each step, the item is assigned to the bin with the maximum score.
  If a bin's remaining capacity equals the maximum capacity (i.e., it is unused), it will not be considered.
  The final goal is to **minimize the number of used bins**.
- **Function signature**: `score(item: int, bins: np.ndarray) -> np.ndarray`
- **Inputs**:
  * `item` (int): The size of the current item to be packed.
  * `bins` (np.ndarray): The remaining capacities of feasible bins (bins where the item fits,
    i.e., bins with remaining capacity >= item size).
- **Output**:
  * `scores` (np.ndarray): A score for each feasible bin. The bin with the highest score
    will be selected for placement.
- **Constraints**:
  * `item` is of type int.
  * `bins` and `scores` are NumPy arrays of the same shape.
  * Only feasible bins are passed to the function (capacity >= item size).
  * The function should be self-consistent and handle edge cases.
- **Bin packing setup**:
  * Items arrive one at a time (online setting).
  * Bin capacity is 100.
  * Instances contain 5,000 items each drawn from a Weibull distribution.
  * There are 5 test instances.

EVALUATION:
- **Fitness** (maximize): Negative of the excess ratio over the L1 lower bound.
  A fitness of 0.0 means optimal packing matching the lower bound.
  Higher values (closer to 0) are better.
- **excess_pct**: The percentage excess over the L1 lower bound (lower is better).
- **avg_num_bins**: Average number of bins used across instances (lower is better).
- **eval_time**: Execution time in seconds.

COMPUTATIONAL RESOURCES & IMPLEMENTATION GUIDELINES:
**Core packages**: numpy, scipy
- The function must be efficient: it is called once per item (5,000 times per instance, 25,000 total).
- Avoid heavy computation inside the score function; prefer vectorized NumPy operations.
- The function should be deterministic for reproducibility.

DESIGN TIPS:
- Classic heuristics: Best Fit (minimize remaining space), First Fit, Worst Fit, etc.
- Consider combining multiple signals: remaining capacity, item-to-bin ratio, distribution of gaps.
- Non-linear transformations (exponential, logarithmic) of remaining space can be effective.
- Penalizing bins that would leave very small residual capacity (unusable gaps) can help.
- The scoring function should be sufficiently complex to achieve good performance.
- Ensure self-consistency: the function must always return valid scores for the given bins.

COMPUTATIONAL BUDGET:
- **Time limit**: 30 seconds maximum execution time.
- **Memory limit**: 2 GB.

KNOWN BASELINES:
- Best Fit heuristic: ~2-3% excess over L1 bound.
- State-of-the-art evolved heuristics (EoH/FunSearch): <1% excess over L1 bound.
