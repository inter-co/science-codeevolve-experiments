3.  **Fitness Function (Evaluation)**:

    *   **Objective Term**: `sum_radii = sum(r_i)`. This should be maximized.
    *   **Constraint Violations (Penalties)**:
        *   **Containment Penalty**: For each circle `i`, calculate violations if `xi - ri < 0`, `xi + ri > 1`, `yi - ri < 0`, or `yi + ri > 1`. The penalty for a single circle can be `max(0, ri - xi) + max(0, xi + ri - 1) + max(0, ri - yi) + max(0, yi + ri - 1)`. Sum these for all circles.
        *   **Non-overlap Penalty**: For every unique pair of circles `(i, j)`, calculate the Euclidean distance `d_ij = sqrt((xi-xj)² + (yi-yj)²)` and the minimum allowed distance `min_d_ij = ri + rj`. If `d_ij < min_d_ij`, there is an overlap. The penalty for a pair can be `max(0, min_d_ij - d_ij)`. Sum these for all pairs.
    *   **Combined Fitness**: The fitness function should return a tuple, typically `(sum_radii - K_overlap * total_overlap_penalty - K_containment * total_containment_penalty,)`. The leading comma makes it a tuple, which `deap` expects for multi-objective or single-objective maximization.
        *   `K_overlap` and `K_containment` are large positive penalty coefficients (e.g., 1000 or more) to strongly discourage constraint violations. Consider experimenting with **non-linear penalties** for overlaps (e.g., `max(0, min_d_ij - d_ij)^2` for severe violations) to create a stronger gradient and more effectively push circles apart, which can help the GA escape local optima.
