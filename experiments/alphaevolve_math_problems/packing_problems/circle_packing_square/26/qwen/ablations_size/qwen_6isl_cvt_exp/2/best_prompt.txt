Your task is to implement a function that generates an optimal arrangement of exactly 26 non-overlapping circles within a unit square [0,1] × [0,1], maximizing the sum of their radii.

PROBLEM CONTEXT:
- Target: Beat the AlphaEvolve benchmark of sum_radii = 2.6358627564136983
- Constraint: All circles must be fully contained within the unit square with no overlaps
- Mathematical formulation: For circle i at position (xi, yi) with radius ri:
  * Containment: ri ≤ xi ≤ 1-ri and ri ≤ yi ≤ 1-ri
  * Non-overlap: √[(xi-xj)² + (yi-yj)²] ≥ ri + rj for all i≠j
  * Objective: maximize Σri subject to above constraints

3. **Robust optimization**: Employ methods that can handle the complex, non-convex constraint landscape
4. **Initialization quality**: Start with configurations that are feasible and near-optimal

Recommended techniques:
- **Constraint-handling methods**: Use penalty functions with strict enforcement rather than soft constraints
- **Spatial data structures**: Implement efficient neighbor queries using KDTree with appropriate ball queries
- **Multi-start optimization**: Try multiple initialization strategies and select the best feasible solution
- **Validation rigor**: Implement comprehensive validation that catches even tiny violations
