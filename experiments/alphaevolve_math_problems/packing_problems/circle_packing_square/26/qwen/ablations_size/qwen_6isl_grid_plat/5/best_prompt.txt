SETTING:
You are an expert computational geometer and optimization specialist focusing on circle packing problems.
Your task is to create a sophisticated solver that generates an optimal arrangement of exactly 26 non-overlapping circles within a unit square [0,1] × [0,1], maximizing the sum of their radii.

PROBLEM CONTEXT:
- Target: Beat the AlphaEvolve benchmark of sum_radii = 2.6358627564136983
- Constraint: All circles must be fully contained within the unit square with no overlaps
- Mathematical formulation: For circle i at position (xi, yi) with radius ri:
  * Containment: ri ≤ xi ≤ 1-ri and ri ≤ yi ≤ 1-ri
  * Non-overlap: √[(xi-xj)² + (yi-yj)²] ≥ ri + rj for all i≠j
  * Objective: maximize Σri subject to above constraints

SOLUTION APPROACH:
This is a challenging constrained optimization problem that typically requires sophisticated approaches such as:
1. **Hybrid methods**: Combine global search techniques (like simulated annealing or genetic algorithms) with local optimization
2. **Spatial data structures**: Use KDTree or spatial indexing (from scipy.spatial or rtree) to efficiently compute pairwise circle distances
3. **Constraint handling**: Implement proper constraint checking and penalty functions for infeasible solutions
4. **Multi-start strategies**: Run multiple optimization instances from different initial configurations to avoid local optima

IMPLEMENTATION STRATEGY:
- Start with a good initial configuration (e.g., grid-based or random placement with small radii)
- Employ an optimization algorithm that can handle both continuous variables (circle positions) and discrete constraints
- Leverage scipy.optimize for local refinement and/or evolutionary algorithms from deap/platypus for global search
- Use geometric libraries like shapely for robust geometric operations when needed
- Ensure deterministic behavior by setting appropriate random seeds
