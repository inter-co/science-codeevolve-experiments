SETTING:
You are an expert in discrete geometry and packing theory with deep knowledge of circle arrangement algorithms.
Your task is to evolve a constructor function implementing a **multi-stage geometric placement strategy** that generates 32 non-overlapping circles within a unit square [0,1] × [0,1], maximizing the sum of their radii.

ALGORITHMIC INSPIRATION:
Consider these fundamentally different approaches from packing literature:
- **Lattice-based initialization**: Start from hexagonal or square grid patterns, then adapt to square boundary constraints
- **Maximal hole filling**: Iteratively place largest possible circles in remaining void regions using spatial data structures
- **Energy minimization**: Model circles as charged particles with repulsive forces, allowing natural spacing through gradient descent or physics simulation
- **Recursive partitioning**: Divide the square into sub-regions and solve smaller packing subproblems, then refine boundaries
- **Boundary-to-interior construction**: Place circles along edges first (exploiting boundary constraints), then fill interior optimally

PROBLEM CONTEXT:
- Target: Beat the AlphaEvolve benchmark of sum_radii = 2.937944526205518
- Constraint: All circles must be fully contained within the unit square with no overlaps
- Mathematical formulation: For circle i at position (xi, yi) with radius ri:
  * Containment: ri ≤ xi ≤ 1-ri and ri ≤ yi ≤ 1-ri
  * Non-overlap: √[(xi-xj)² + (yi-yj)²] ≥ ri + rj for all i≠j
  * Objective: maximize Σri subject to above constraints

IMPLEMENTATION STRATEGY GUIDANCE:
Your solution should follow a **constructive + refinement** paradigm:
1. **Phase 1 - Intelligent Initialization**: Generate a feasible starting configuration using geometric insights (NOT random placement)
   - Exploit symmetry properties of the unit square

3. **Phase 3 - Radius Maximization**: With fixed positions, solve the linear programming problem of maximizing radii subject to non-overlap constraints

KEY INSIGHT: The sum of radii is highly sensitive to the geometric distribution pattern. Uniform spacing is often suboptimal—explore **adaptive density patterns** where circles near boundaries can be larger.
