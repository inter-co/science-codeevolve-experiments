Your task is to implement a global optimization strategy to solve this circle packing problem. Given the non-convex nature, high dimensionality (21 * 3 + 1 = 64 variables), and non-linear constraints, a metaheuristic approach is highly recommended.

**1. Define the Optimization Variables:**
   - The primary variables to optimize are the (x, y) coordinates and radius (r) for each of the 21 circles. This means 21 * 3 = 63 variables.
   - Additionally, you need to optimize the rectangle's dimensions. Since the perimeter is 4 (width + height = 2), you only need to optimize one dimension, e.g., `rectangle_width`. `rectangle_height` can then be derived as `2 - rectangle_width`.
   - Consider a single flattened array for all these variables: `[x1, y1, r1, ..., x21, y21, r21, rectangle_width]`.

**2. Design the Objective Function (Fitness Function):**
   - The goal is to maximize `sum_radii`.
   - Incorporate all constraints as penalties. The objective function should return a *lower* value for invalid configurations (e.g., a negative sum or `sum_radii - penalty_term`). A common approach is `sum_radii - C1*overlap_penalty - C2*boundary_penalty - C3*negative_radius_penalty`.
   - **Penalties for Constraint Violations:**
     - **Overlap Penalty:**
       - Calculate pairwise Euclidean distances between circle centers using `scipy.spatial.distance.pdist`.
       - For any pair `i, j`, if `distance(center_i, center_j) < r_i + r_j`, there's an overlap. The penalty could be `sum(max(0, r_i + r_j - distance(center_i, center_j)))` over all overlapping pairs.
     - **Containment Penalty:**
       - For each circle `i` and rectangle dimensions `width`, `height`:
         - `x_i - r_i < 0` (left boundary violation)
         - `x_i + r_i > width` (right boundary violation)
         - `y_i - r_i < 0` (bottom boundary violation)
         - `y_i + r_i > height` (top boundary violation)
       - The penalty could be `sum(max(0, r_i - x_i) + max(0, x_i + r_i - width) + max(0, r_i - y_i) + max(0, y_i + r_i - height))` over all circles.
     - **Positive Radii Penalty:**
       - For any `r_i <= 0`, add a penalty, e.g., `sum(max(0, -r_i))`. The problem explicitly states "All radii must be positive."

**3. Choose and Configure a Global Optimizer:**
   - Consider packages like `scikit-opt` (e.g., `GA` for Genetic Algorithm, `PSO` for Particle Swarm Optimization) or `deap`. `scikit-opt.GA` is a good starting point.
   - **Bounds:** Define appropriate bounds for each variable:
     - `x_i, y_i`: Should be within `[0, 2]` (as max rectangle dimension is 2).
     - `r_i`: Should be positive, e.g., `[1e-6, 1.0]` (a radius cannot exceed 1 if width/height is 2).
     - `rectangle_width`: `[0.1, 1.9]` (to avoid degenerate rectangles).
   - **Initialization:** The optimizer will typically handle initial population generation within the defined bounds.
   - **Iterations/Generations:** Set a reasonable number of iterations or generations, keeping the 360-second time limit in mind. Start with a moderate number and adjust.
   - **Reproducibility:** Ensure `random_state` or `seed` is set for the optimizer for deterministic results.

**4. Implementation Structure:**
   - Create helper functions for clarity:
     - `unpack_variables(individual)`: Takes the flattened array and returns `(circles_coords, radii, width, height)`.
     - `calculate_penalties(circles_coords, radii, width, height)`: Returns the total penalty value.
     - `objective_function(individual)`: Takes the flattened variable array, unpacks it, calculates sum_radii and penalties, and returns the penalized fitness (to be maximized).
   - The main `circle_packing21` function should:
     - Define variable bounds.
     - Initialize and run the chosen optimizer (e.g., `scikit-opt.GA`).
     - Extract the best solution (x, y, r for each circle, and rectangle dimensions) from the optimizer's result.

from sko.GA import GA

# ... helper functions like unpack_variables, calculate_penalties ...

def objective_function(individual):
    circles_coords, radii, width, height = unpack_variables(individual)
    
    sum_radii = np.sum(radii)
    penalties = calculate_penalties(circles_coords, radii, width, height)
    
    # Maximize sum_radii, minimize penalties.
    # Return a single fitness value. Scale penalties appropriately.
    return sum_radii - penalties * 1000 # Penalty coefficient can be tuned

def circle_packing21() -> np.ndarray:
    n_circles = 21
    n_vars = n_circles * 3 + 1 # x, y, r for each circle + rectangle_width

    return result_circles
